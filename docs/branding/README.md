# Kernel and the Foundry project banner

Kernel is the driver-research duck with red pixel horns and a cyan chip. The mascot identifies this project within the Foundry Computing workshop.

The banner uses the Foundry silver circuit F, dark navy and electric blue palette, circuit and pixel details, and “IT solutions. Built to last.” tagline. The duck uses the owner-approved 8-bit pixel-art style.

Artwork was generated with the built-in image tool from existing Foundry marketing references and reviewed for this repository. Original technical README content and project status were preserved. The artwork is decorative and does not imply software readiness or validation.

When changing the banner, preserve the Foundry identity and the project duck. Keep the image at this repository-local path so private repositories do not depend on publicly hosted project assets.
